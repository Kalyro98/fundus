# Fundus

Fundus ist ein Datei-Explorer für macOS: Tabs wie unter Windows, geteilte Ansicht, echtes Ausschneiden und eine Suche, die jede Datei in Millisekunden findet.

Dieses Projekt enthält nur die fertigen Fassungen, nicht den Quelltext. Die neueste Fassung liegt unter **Releases**.

## Installieren

1. Unter Releases die neueste `Fundus-x.y.dmg` laden.
2. Öffnen und Fundus in den Ordner „Programme“ ziehen.
3. Fundus starten, die Einrichtung führt durch die Freigaben.

## Updates

Fundus sucht selbst nach neuen Fassungen und zeigt unten in der Seitenleiste einen Hinweis. Übernommen wird nur eine App mit derselben Signatur.

Voraussetzung: macOS 26 oder neuer.
